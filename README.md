# 🎓 Student Grade Tracker

A simple and attractive Student Grade Tracker web application built using Java, MySQL, HTML, CSS and JavaScript.

## 🚀 Features

- Add student name and marks
- Automatically calculate grades
- Store student records in MySQL
- Display saved student records
- Delete student records
- Java backend using JDBC
- Simple and user-friendly interface

## 🛠️ Technologies Used

- Java
- Java DSA / ArrayList
- MySQL
- JDBC
- HTML
- CSS
- JavaScript
- Git & GitHub
